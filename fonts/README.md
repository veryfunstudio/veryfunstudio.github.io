# Self-hosted fonts

The site loads these files locally. It does not need Google Fonts requests at runtime.

| Family | Files | Licence source |
| --- | --- | --- |
| Space Grotesk | `space-grotesk-400.woff2` (variable, 300–700) | [Google Fonts / Space Grotesk](https://github.com/google/fonts/blob/main/ofl/spacegrotesk/OFL.txt) |
| DM Sans | `dm-sans-400.woff2` (variable, 100–1000) | [Google Fonts / DM Sans](https://github.com/google/fonts/blob/main/ofl/dmsans/OFL.txt) |
| DM Mono | `dm-mono-400.woff2`, `dm-mono-500.woff2` | [Google Fonts / DM Mono](https://github.com/google/fonts/blob/main/ofl/dmmono/OFL.txt) |
| Instrument Serif | `instrument-serif-400.woff2`, `instrument-serif-italic.woff2` | [Google Fonts / Instrument Serif](https://github.com/google/fonts/blob/main/ofl/instrumentserif/OFL.txt) |

Full copyright and SIL Open Font License notices are retained in the adjacent `OFL-*.txt` files. These fonts keep their own licences. The OG generator uses the same local font files and decoded game imagery.
